# Build with Kloudy

This repository gives developers the materials to make compatible destinations, integrate their bots, and test public contracts.

Included: schemas, example cards, client-side tooling, draft connector definitions, and integration guides. These materials can be copied and modified under Apache-2.0.

Excluded: the Kloudy product UI and device adapters, proprietary browser execution, hosted service control, directory implementation/data, credential and permission authority, billing and ad-matching implementations, private operational plans, and deployment infrastructure.

An open client or schema is not a complete distribution of Kloudy and does not grant control over a hosted service. Access remains subject to the service's authorization and supported capabilities. Interface compatibility does not imply service availability.

Any future exports must be selected file by file from a reviewed allowlist. Never mirror internal repositories or publish a private Git history. Do not distribute internal source maps, service secrets, or admin credentials with client examples.
