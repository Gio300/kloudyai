# Contributing

Contributions should help developers connect their own destinations and tools to Kloudy. Keep examples fictional and free of credentials. Open an issue or pull request with the compatibility problem and the intended behavior.

Run `npm run check`. Describe any protocol change and avoid claiming compatibility with an unimplemented service. Contributions to this repository are under Apache-2.0.

See [the public boundary](docs/PUBLIC_BOUNDARY.md) before adding files.
